The first release of the Cloud Registry UI, a web app for browsing and
managing services in a [Cloud
Registry](https://cloud-registry.readthedocs.io/en/latest/), published as the
image `elixircloud/cloud-registry-ui:1.0.0-rc1` and tested against
cloud-registry 1.0.0rc1 (the registry spells its pre-releases the PEP 440
way, the app the SemVer way). See the [operator guide](../operator-guide/index.md)
to deploy it and the [user guide](../user-guide/index.md) to use it.

## Features

- Browse, search and filter services, with their details, verifications and
  pending entries
- Register, edit, rename and delete services; admins can choose service IDs
  (#92)
- Manage access: grant and revoke roles of users and groups, and invite users
  to services by link (#105, #114)
- Show the limit of services per user clearly (#109, #116)
- Switch between user and admin mode (#93)
- Show and approve pending services and service types, and add and delete
  service types
- Log in with one or several OpenID Connect providers (such as LS Login),
  configured at start (#86)
- Configure the registry's address; the allowed environments and URL schemes
  of services are read from the registry's service info (#128)
- Show the registry's registration rules on the service info page, offer
  adding service types only where the registry accepts new types, and
  explain conflicts of service types (#131)
- Pick service types from the registered ones in the edit form, as in the
  form for new services; offer new types only to users who may add them
  (#130, #148)
- Check registrations in the create form before sending them, as the
  registry does (required fields, URLs and their schemes, environments,
  lengths), and offer new types there only where the registry accepts them
  (#35, #149)

## Security

- Login with PKCE and a nonce; the app checks the issuer, audience, expiry and
  party of ID tokens and the issuer name of responses (RFC 9207)
- Fresh credentials for every login (#96)
- Hardened image and security headers; settings and secrets are read at start
  and stay out of the image
